## 📊 Project Overview

This project transforms raw healthcare data into clear KPIs, interactive visualizations, and actionable business insights. It covers patient admissions, demographics, medical conditions, billing, treatment trends, and outcomes through a fully interactive Power BI dashboard.

## 🎯 Objectives

- Analyze patient admissions and demographics
- Understand medical condition trends
- Track billing and healthcare metrics
- Identify treatment and patient outcome patterns
- Build an interactive and user-friendly Power BI dashboard
- Support data-driven healthcare decisions

## 📈 Key Dashboard Insights

The dashboard delivers analysis across the following areas:

- 👥 **Patient Demographics** — age, gender, and population distribution
- 🏥 **Hospital & Admission Analysis** — admission volume and patterns
- 🩺 **Medical Conditions** — most common conditions and diagnoses
- 💰 **Billing & Revenue** — cost breakdowns and revenue trends
- 💊 **Treatment & Medication Trends** — prescribed treatments and outcomes
- 📅 **Admission Trends** — time-based patterns and seasonality
- 📊 **Key Performance Indicators (KPIs)** — high-level operational metrics

## 🔄 Project Workflow

## 🚀 Getting Started

1. Clone or download this repository.
2. Extract `Papollo.zip` to access the `.pbix` Power BI file.
3. Open the file in [Power BI Desktop](https://www.microsoft.com/en-us/download/details.aspx?id=58494).
4. Explore the report pages, slicers, and drill-throughs to interact with the data.

## 💡 Business Value

This dashboard helps healthcare stakeholders monitor key metrics, identify trends, understand patient patterns, and make informed, data-driven decisions.
