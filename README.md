# 🏥 Hospital Data Analytics | Power BI Dashboard

## 📊 Project Overview

**Turning Hospital Data into Actionable Insights** — an interactive Power BI dashboard designed to analyze hospital data and provide meaningful insights for data-driven decision-making.

The project focuses on transforming raw healthcare data into clear KPIs, interactive visualizations, and actionable business insights.

## 🎯 Objectives

* Analyze patient admissions and demographics
* Understand medical condition trends
* Track billing and healthcare metrics
* Identify treatment and patient outcome patterns
* Build an interactive and user-friendly Power BI dashboard
* Support data-driven healthcare decisions

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Modeling**
* **Data Cleaning**
* **Data Visualization**

## 📈 Key Dashboard Insights

The dashboard provides analysis across areas such as:

* 👥 Patient Demographics
* 🏥 Hospital & Admission Analysis
* 🩺 Medical Conditions
* 💰 Billing & Revenue
* 💊 Treatment & Medication Trends
* 📅 Admission Trends
* 📊 Key Performance Indicators (KPIs)

## 🔄 Project Workflow

**Raw Data → Data Cleaning → Power Query → Data Modeling → DAX Measures → Dashboard → Business Insights**

## 💡 Business Value

This dashboard helps healthcare stakeholders monitor important metrics, identify trends, understand patient patterns, and make informed decisions using data.
